Refactor Rationale — Screen C

  • ✓All static values de-blued — #008C95 removed from TR number, description, status, dates, and people's names. Blue is now reserved only for actual navigation links (person names link to profiles). Everything else uses $text or $text-muted (dark/gray)
  • ✓RTCD overdue warning promoted to a danger callout — replaces bare red text with a left-bordered danger alert container. The date itself also renders in $brand-danger (#e33f4e) to communicate the status visually at the data level
  • ✓PRELIMINARY warning promoted to an info callout — italic red text replaced with a blue left-border informational alert using italic styling for the note character, contained within the Meeting Notes card
  • ✓Status values converted to semantic badges — "Closed" is a gray badge, "Delivered" is green, "Complete" is teal. Identical labels show at a glance vs. requiring text parsing
  • ✓Legend strip contained and redesigned — emoji icons replaced with CSS color dots ($yz-red, $warning, orange). Now a proper header bar with a "Status Guide:" label, not floating content
  • ✓Left rail extended to full navy height — "Close / Test Details / Overview" sidebar becomes part of the navy chrome with icon+label buttons; active state uses Yazaki Red background tint
  • ✓"TEST DETAILS" embedded tab removed — replaced with a tab bar in the page header (Overview | Test Details) — standard Mendix tab pattern applied at the page level where it belongs
  • ✓Boxed number "1" pagination widget replaced — sequence indicator for test items now uses a circular navy-blue badge (#008C95 bg) — semantically a sequence number, not a page selector
  • ✓Test item dates use date cells — Start Date, Completion Date, Total Days, and "Is There A failure?" now live in a 2×2 grid of light-bordered date cells. Labels are plain gray, values are dark — not blue
  • ✓"Is There A failure?" label de-blued — was rendered in brand-primary blue (looked like a link); now muted gray 11px uppercase label within the date cell
  • ✓"PROJECT UDPATES" typo fixed to "Project Updates"
  • ✓"TEST UPDATES" purple color removed — was using an orphan color ($ActionColor or local variable). Now uses the shared $font-color-muted uppercase section header pattern
  • ✓Completion summary mini-card added — shows 5/5 deliverables complete with a progress bar. Optional UX recommendation; labeled clearly if presented to client
  • ✓Empty state for Project Updates — "No Items Found" plain text replaced with icon + message + sub-text using shared empty state pattern from Screen A

Mendix Component Opportunities

  • ▸TR Overview Page Template Page Template
    3-column detail view: TR Details | Deliverables | Updates. Used for all Open Request overviews. Parameterized for different TR types (Analysis, Validation, etc.).
  • ▸Alert Callout — Danger / Warning / Info Building BlockSCSS Pattern
    .aft-alert.danger / .warning / .info — 3px left border + tinted background. Replaces all floating red text and italic warnings across the application. Highest-reuse opportunity.
  • ▸Legend Bar Building Block
    Contained horizontal strip with color-dot legend items. Reusable on any page with visual status indicators in the data grid or overview.
  • ▸Leg / Chapter Accordion Building Block
    Navy header bar (Leg N | ID | Status badge) with expandable test item rows. Reuse across all test request types with multiple legs.
  • ▸Test Item Row Building BlockShared Pattern
    Sequence badge + test ID + name + status + 2×2 date grid. Standard test item display across all chapters. The date cell grid is the reusable sub-pattern.
  • ▸Deliverables Status Card Building Block
    Label + semantic badge rows. Reuse on all TR overview pages. Badge color map: Delivered → green, Complete → teal, Pending → amber, Not Started → gray.
  • ▸Overdue Date Display Utility ClassSCSS Pattern
    .value-overdue { color: $brand-danger; font-weight: 700; } — applied conditionally via Mendix expression when a date is in the past. Surfaces the status at the data level without needing a separate text note.
  • ▸Navy Rail Navigation Shared PatternPage Template
    Left rail at full nav height (52px topbar + content height) in $topbar-bg navy. Icon+label buttons with active state (YazakiRed tint). Extends the same rail used on detail pages — consistent chrome across the application.
